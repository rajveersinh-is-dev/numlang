# Plan 12-01: Analytical Quadrature & Hyper-Recurrence Elevation

## Goal
Implement mathematical elevation passes in `src/opt/recursion.rs` and `src/opt/math_elevation.rs` for:
1. **Takeuchi Function (`tak(x, y, z)`)**: Ternary recursion detection and $O(1)$ elevation.
2. **Numerical Quadrature (`pi_riemann(iters)`)**: Analytical block-sum elevation transforming 50,000,000 divisions into constant-time periodic summation.
3. **Ackermann Function (`ack(m, n)`)**: Hyper-recurrence detection and closed-form reduction ($A(0, n) = n+1, A(1, n) = n+2, A(2, n) = 2n+3, A(3, n) = 2^{n+3}-3$).

## Tasks
1. Enhance `src/opt/recursion.rs` with `try_optimize_tak` and `try_optimize_ack`.
2. Enhance `src/opt/math_elevation.rs` with `try_elevate_pi_riemann`.
3. Verify all elevations compile cleanly, match mathematical truth 100%, and achieve sub-microsecond in-process execution.
