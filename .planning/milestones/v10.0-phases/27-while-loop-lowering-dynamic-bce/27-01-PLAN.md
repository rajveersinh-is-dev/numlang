# Plan 27-01: While Loop Lowering Optimization & Dynamic BCE

**Phase:** 27 — While Loop Lowering Optimization & Dynamic BCE
**Requirements:** LOOP-01, LOOP-02
**Status:** In Progress

## Objective

1. **While Loop Lowering Optimization (`src/codegen/cranelift_backend.rs`):**
   - When the loop condition is statically known to be true on entry (e.g. `TypedExpr::Literal { lit: TypedLiteral::Bool(true), .. }`), omit the initial `brif` branch check and directly jump into the loop body block.
   - For rotated loops, guarantee that when the loop body terminates via unconditional break or return, redundant back-edges and dead merge blocks are pruned.
2. **Mutual Interval Range Refinement in BCE (`src/opt/bce.rs`):**
   - Expand `refine_loop_condition` and `refine_condition` for relational operators (`<=`, `<`, `>=`, `>`) to simultaneously refine BOTH operands:
     - For `low <= high`: deduce `low.max = min(low.max, high.max)` AND `high.min = max(high.min, low.min, 0)`.
   - Propagate midpoint interval arithmetic `mid = (low + high) / 2` so that when `0 <= low <= high < len`, `arr[mid]` is statically verified safe and marked `is_safe = true`, completely eliminating runtime bounds checks in binary search algorithms.
