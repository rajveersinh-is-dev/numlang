<objective>
Implement the Intermediate Representation (IR) data structures, lower the typed AST to IR basic blocks and instructions, and support `--emit-ir` in the compiler CLI.

Purpose: Provide a clear machine-independent IR abstraction for arithmetic, variable assignments, control flow blocks, and function calls.
Output: `src/ir/` module, typed AST to IR lowering pass, `--emit-ir` CLI flag, and unit/integration tests.
</objective>

<execution_steps>
1. Create `src/ir/mod.rs` defining `IrProgram`, `IrFunction`, `BasicBlock`, `Instruction`, `Value`, and text printer.
2. Create `src/ir/lower.rs` implementing AST-to-IR lowering (arithmetic, variables, function calls, `if`/`else` branching, `while` loop blocks).
3. Expose `pub mod ir;` in `src/lib.rs`.
4. Update `src/main.rs` to support `--emit-ir` and output the formatted IR.
5. Create `tests/codegen_tests.rs` with tests verifying IR lowering and text output.
</execution_steps>
