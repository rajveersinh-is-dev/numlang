# Plan 31-01: Tail-Call Loop Transformation & Leaf Recursion Unrolling

**Phase:** 31 - Tail-Call Loop Transformation & Leaf Recursion Unrolling
**Requirements:** REC-01, REC-02
**Status:** Complete

## Objective

Eliminate unnecessary function call frames in recursive workloads through compiler-level Tail-Call Elimination (TCO) and accumulator recursion loop lowering:
1. Eliminate tail calls in self-recursive functions (`tak`, `ack`) by replacing outer self-recursive calls with in-place parameter re-assignments and loop iterations.
2. Optimize binary recurrence relations (`fib` 35) by lowering associative second recursive calls into accumulator loops, matching LLVM's tail recursion elimination.

## Implementation Details

1. In `src/opt/recursion.rs`:
   - Identify self-recursive functions with tail calls (`has_self_tail_call_block`).
   - Create mutable shadow variables for parameters and rename references.
   - Replace tail `Return(Some(Call))` with temporary argument bindings and parameter assignments.
   - Wrap the transformed body in `while true`.
2. In `src/codegen/cranelift_backend.rs`:
   - Detect binary recurrence trees (`try_lower_binary_recurrence_tree`).
   - Lower the second recursive call into an accumulator while-loop (`while cur >= 2 { sum += f(cur - 1); cur -= 2; } return sum + cur;`).
3. In `src/codegen/cranelift_backend.rs`:
   - Narrow dynamic non-negative division and modulo to 32-bit `udiv`/`urem` when operands fit in 32 bits, slashing integer square root division latency.
