<objective>
Enable native host CPU feature detection and configure Cranelift's TargetIsaBuilder with architecture-specific flags (AVX2, FMA, SSE4.2, BMI2).

Purpose: Specialize native machine code generation to the host CPU, allowing Cranelift to emit vector and fused instructions instead of generic x86_64 fallback code.
Output: Target CPU specialization in `src/codegen/cranelift_backend.rs` and verification tests in `tests/simd_feature_tests.rs`.
</objective>

<execution_steps>
1. Inspect Cranelift 0.135 ISA builder setting APIs for target CPU feature flags.
2. In `CraneliftCompiler::new()`, detect host CPU features dynamically via `std::is_x86_feature_detected!` for `avx2`, `fma`, `sse4.2`, `bmi1`, `bmi2`.
3. Enable detected flags on `isa_builder`.
4. Add verification tests in `tests/simd_feature_tests.rs` ensuring compilation succeeds and produces valid binaries with target features enabled.
</execution_steps>
