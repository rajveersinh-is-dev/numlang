<objective>
Implement hardware-accelerated FMA instructions and 4-way independent accumulator unrolling for vector math intrinsics (`dot`, `sum`, `vec_add`).

Purpose: Achieve peak theoretical floating-point and integer throughput on x86 hardware by breaking accumulator dependency chains and saturating CPU vector execution pipelines.
Output: FMA-accelerated vector lowering in `src/codegen/cranelift_backend.rs` and comprehensive verification tests in `tests/simd_feature_tests.rs`.
</objective>

<execution_steps>
1. Update `dot` intrinsic lowering in `src/codegen/cranelift_backend.rs`:
   - For floats, use `builder.ins().fma(val_a, val_b, acc)` with 4 independent accumulator registers (`acc0`, `acc1`, `acc2`, `acc3`), then sum the 4 accumulators.
   - For integers, unroll with 4 independent accumulators (`acc0`, `acc1`, `acc2`, `acc3`) combining with `imul` and `iadd`.
   - Handle remainder elements when array length is not a multiple of 4.
2. Update `sum` intrinsic lowering with 4-way unrolled independent accumulators.
3. Update `vec_add` intrinsic lowering with 4-way unrolled loads and stores.
4. Add verification tests in `tests/simd_feature_tests.rs` testing FMA accuracy, multi-accumulator correctness, and execution on arrays of various sizes.
</execution_steps>
