<objective>
Implement loop unrolling optimization passes in the Cranelift codegen backend for fixed-size iterations, general induction loops, and 8x multi-accumulator vector operations.

Purpose: Maximize instruction-level parallelism (ILP), eliminate branch penalties, and saturate CPU execution pipelines to beat compiled C and Rust.
Output: Unrolled loop codegen in `src/codegen/cranelift_backend.rs` and verification tests in `tests/loop_unrolling_tests.rs`.
</objective>

<execution_steps>
1. Implement full unrolling for small fixed loops (N <= 16) in `src/codegen/cranelift_backend.rs`:
   - Detect when an induction variable is initialized to 0 immediately before `while i < N` (or `i <= N - 1`), with step `i = i + 1`.
   - Replicate body statements sequentially `N` times in straight-line code with zero branches and zero blocks.
2. Implement 4x unrolling for general induction loops in `src/codegen/cranelift_backend.rs`:
   - Detect induction loops `while i < limit` where `i` increments by 1 and is not otherwise reassigned.
   - Emit an unrolled loop block with condition `i + 4 <= limit` executing 4 iterations per cycle.
   - Emit a scalar cleanup block with condition `i < limit` executing remainder iterations (0..3).
3. Upgrade vector operations (`dot`, `sum`, `vec_add`) to 8x/4x unrolling:
   - For `dot`: 8 independent accumulators `acc0..acc7` with dual FMA issue saturation when length >= 8.
   - For `sum`: 8 independent accumulators `acc0..acc7` when length >= 8.
   - For `vec_add`: 8-way pipelined load/add/store when length >= 8.
4. Write comprehensive tests in `tests/loop_unrolling_tests.rs` to verify mathematical equivalence and correct execution.
5. Run full test suite and comparative benchmarks.
</execution_steps>
