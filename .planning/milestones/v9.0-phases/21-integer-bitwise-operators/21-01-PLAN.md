# Plan 21-01: Integer Bitwise Operators

**Phase:** 21 — Integer Bitwise Operators
**Requirements:** BIT-01, BIT-02
**Status:** Pending

## Objective

Implement native bitwise operators (\&\, \|\, \^\, \<<\, \>>\) across the entire numlang compiler pipeline (lexer, Pratt parser, AST, typechecker, IR lowerer, and Cranelift backend) to eliminate expensive division/modulo arithmetic in bit-manipulation kernels (e.g. Stein's Binary GCD, Rule 110).

## Proposed Changes

### Lexer & Tokenizer
#### [MODIFY] \src/token.rs- Add tokens:
  - \Token::Ampersand\ (\&\)
  - \Token::Pipe\ (\|\)
  - \Token::Caret\ (\^\ - bitwise XOR)
  - \Token::Shl\ (\<<\)
  - \Token::Shr\ (\>>\)
  - \Token::StarStar\ (\**\ - exponentiation)

### AST & Parser
#### [MODIFY] \src/ast.rs- Add \BinaryOp::BitAnd\, \BinaryOp::BitOr\, \BinaryOp::BitXor\, \BinaryOp::Shl\, \BinaryOp::Shr\.

#### [MODIFY] \src/parser/expr.rs- Update Pratt parser \infix_binding_power\ with standard precedence:
  - Multiplicative: \*\, \/\, \%  - Additive: \+\, \-  - Bitwise Shifts: \<<\, \>>  - Relational: \<\, \<=\, \>\, \>=  - Equality: \==\, \!=  - Bitwise AND: \&  - Bitwise XOR: \^  - Bitwise OR: \|
### Type Checker
#### [MODIFY] \src/typecheck/checker.rs- Enforce that operands for bitwise operations (\&\, \|\, \^\, \<<\, \>>\) must be integer types (\i64\, \i32\).
- Enforce both operands match or return appropriate integer type.
- Reject floats (\64\, \32\) and non-integers.

### IR & Codegen
#### [MODIFY] \src/ir/mod.rs\ & \src/ir/lower.rs- Add \IrOp::BitAnd\, \IrOp::BitOr\, \IrOp::BitXor\, \IrOp::Shl\, \IrOp::Shr\.
- Lower typed bitwise binary expressions to IR instructions.

#### [MODIFY] \src/codegen/cranelift_backend.rs- Lower bitwise binary operations to Cranelift instructions:
  - \BitAnd\: \uilder.ins().band(l, r)  - \BitOr\: \uilder.ins().bor(l, r)  - \BitXor\: \uilder.ins().bxor(l, r)  - \Shl\: \uilder.ins().ishl(l, r)  - \Shr\: \uilder.ins().sshr(l, r)\ (arithmetic/signed shift right)

### Benchmarks & Tests
#### [NEW] \	ests/bitwise_tests.rs- Comprehensive unit tests verifying bitwise AND, OR, XOR, SHL, SHR operations, precedence, and error diagnostics on invalid types.

#### [MODIFY] \	ests/multi_language_benchmarks.rs- Update Workload 18 (Stein's Binary GCD) to use native bitwise operators \&\, \>>\, eliminating modulo and division arithmetic.
- Measure performance speedup vs baseline.
