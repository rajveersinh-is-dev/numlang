# Plan 22-01: Loop Bounds Check Elimination (BCE)

**Phase:** 22 — Loop Bounds Check Elimination (BCE)
**Requirements:** BCE-01
**Status:** In Progress

## Objective

Implement comprehensive Static Induction Bounds Check Elimination (BCE) across the compiler to eliminate branch and panic checks in tight array-indexing loops (such as N-Queens, Rule 110, and Binary Search) by statically proving index safety through interval/range analysis and symbolic loop bound propagation.

## Proposed Changes

### 1. Semantic Interval & Bound Representation (`src/typecheck/checker.rs`)
- Expand `active_loop_bounds` from `HashMap<String, i64>` to support:
  - Literal upper bounds: `i < N`, `i <= N - 1`
  - Variable upper bounds: `i < n`, `i <= n - 1` (where `n` is bounded by array capacity or caller arguments)
  - Lower bounds: `i >= 0`, `i >= 1`
  - Variable-to-variable relationships (e.g. `row < n`, `col < n`)
- Support tracking bounds of enclosing loop variables in nested loops without shadowing bugs.

### 2. Affine Index & Expression Safety Analysis
- Extend index safety verification in `TypedStmt::IndexAssign` and `TypedExpr::Index`:
  - Single variable: `arr[i]` when `0 <= min(i)` and `max(i) < len`.
  - Offset indexing: `arr[i + c]` or `arr[i - c]` (e.g. `arr[i - 1]`, `arr[i + 1]` in cellular automaton / stencils). If `min(i) + c >= 0` and `max(i) + c < len`, mark `is_safe = true`.
  - Sum / diagonal indexing: `diag[r + c]` when `max(r) + max(c) < len`.
  - Anti-diagonal indexing: `diag[r - c + offset]` when minimum and maximum are proven within `[0, len)`.
  - Variable upper bound: `arr[i]` where `i < n` and `n <= len` (either via parameter bounds, local constants, or array capacity).

### 3. Dedicated Range Analysis / BCE Pass (`src/opt/bce.rs`)
- Add `src/opt/bce.rs` (integrated into `src/opt/mod.rs`):
  - Traverses `TypedProgram` after initial typing and constant argument propagation.
  - Computes known variable intervals `[min, max]` per block.
  - Marks `is_safe = true` on all provably safe `TypedExpr::Index` and `TypedStmt::IndexAssign` instances.

### 4. Verification & Benchmarking
- Add comprehensive test cases in `tests/bce_tests.rs`:
  - Variable loop bounds (`while i < n`).
  - Offset indexing (`arr[i - 1]`, `arr[i + 1]`).
  - Multi-variable affine indexing (`arr[r + c]`).
  - Out-of-bounds / unsafe indexing retaining panic traps.
- Measure performance acceleration on N-Queens, Rule 110, and Binary Search.
