# Plan 33-01: Hardware Bit-Manipulation Intrinsics & Loop Recognition

**Phase:** 33 - Hardware Bit-Manipulation Intrinsics & Loop Recognition  
**Requirements:** BIT-01, BIT-02  
**Status:** In Progress  

## Objective

Implement native hardware bit-manipulation intrinsics and pattern-match trailing-zero / popcount loops in the Cranelift backend to execute single-cycle x86-64 machine instructions (`tzcnt`/`bsf`, `popcnt`, `rol`, `ror`), eliminating hundreds of millions of loop iterations in Stein's Binary GCD and Rule 110.

## Implementation Details

1. **Intrinsics in Typechecker (`src/typecheck/checker.rs`)**:
   - Add built-in signatures for:
     - `ctz(x: Int) -> Int`
     - `clz(x: Int) -> Int`
     - `popcnt(x: Int) -> Int`
     - `rotl(x: Int, shift: Int) -> Int`
     - `rotr(x: Int, shift: Int) -> Int`
   - Enforce arguments are integer types (`i64`, `i32`).

2. **Cranelift Backend Lowering (`src/codegen/cranelift_backend.rs`)**:
   - Lower `ctz`: `builder.ins().ctz(arg)`
   - Lower `clz`: `builder.ins().clz(arg)`
   - Lower `popcnt`: `builder.ins().popcnt(arg)`
   - Lower `rotl`: `builder.ins().rotl(arg0, arg1)`
   - Lower `rotr`: `builder.ins().rotr(arg0, arg1)`
   - Update `is_safe_for_select` to include these pure built-in calls.

3. **Loop Recognition & Hardware Lowering (`src/codegen/cranelift_backend.rs`)**:
   - Recognize Kernighan's popcount loop pattern:
     ```rust
     while num != 0 {
         num = num & (num - 1);
         count = count + 1;
     }
     ```
     Lower to direct single-instruction addition: `count += popcnt(num); num = 0;`
   - Recognize single-variable trailing zero elimination loop:
     ```rust
     while (u & 1) == 0 {
         u = u >> 1;
     }
     ```
     Lower to single-cycle count and shift: `let tz = ctz(u); u = u >> tz;`
   - Recognize dual-variable common trailing zero elimination loop:
     ```rust
     while ((u | v) & 1) == 0 {
         u = u >> 1;
         v = v >> 1;
         shift = shift + 1;
     }
     ```
     Lower to single-cycle common trailing zero count and parallel shifts:
     `let tz = ctz(u | v); u = u >> tz; v = v >> tz; shift = shift + tz;`

4. **Integration & Verification**:
   - Create `tests/bit_intrinsics_tests.rs` to verify correctness of all intrinsics and loop pattern transformations.
   - Run multi-language benchmarks for Stein's Binary GCD and Rule 110 to verify runtime reductions.

## Verification Criteria

- All unit tests pass in `tests/bit_intrinsics_tests.rs`.
- Stein's GCD runtime slashes significantly from 484 ms to < 250 ms, beating Rust (457 ms).
- Rule 110 runtime slashes from 107 µs to < 40 µs, beating Rust (66.8 µs) and C (59.3 µs).
- 100% bit-for-bit mathematical results across all benchmarks.
