# Plan 30-01: Branchless Select Predication and CMOV Lowering

**Phase:** 30 - Branchless Select Predication and CMOV Lowering
**Requirements:** PRED-01
**Status:** In Progress

## Objective

Eliminate branch misprediction penalties in tight search and numerical loops by generalizing if-else lowering in src/codegen/cranelift_backend.rs to emit branchless select (CMOV on x86_64).

## Implementation Details

1. In src/codegen/cranelift_backend.rs:
   - Handle asymmetric variable updates across branches (e.g. binary search low = mid + 1 vs high = mid - 1).
   - Handle conditional assignments without else-branch (e.g. conditional swaps in Stein GCD).
   - Evaluate RHS expressions safely and emit builder.ins().select(cond, then_val, else_val).

## Verification Plan
- Test binary search kernel with 2,000,000 lookups, verifying runtime drops drastically from 107 ms to under 45 ms.
- Verify exact bit-for-bit mathematical results across all benchmarks.
