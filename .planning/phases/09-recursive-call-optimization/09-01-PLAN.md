# Plan 09-01: Self-Recursive Call Unrolling & Inline Optimization Pass

**Phase:** 9 — Recursive Call Optimization & Inlining Pass
**Requirement:** REC-01 (Recursive call unrolling expands self-recursive calls by depth 1-2, slashing call frame overhead by 50%+)
**Status:** Pending

## Objective

Implement a high-performance optimization pass in `numlang` that detects self-recursive binary functions (e.g. `fib(n) = fib(n - 1) + fib(n - 2)`) and unrolls the recursion tree by depth 2, replacing deep recursive call frame allocations with algebraic multi-step recurrence (`3 * fib(n - 3) + 2 * fib(n - 4)`). This eliminates >60% of recursive call frames, dropping execution time on `fib(35)` below Rust's 36.49ms baseline.

## Proposed Changes

### Compiler Optimization Module
#### [NEW] `src/opt/mod.rs`
- Define the optimization pipeline entry points (`optimize_program(program: &mut TypedProgram)`).

#### [NEW] `src/opt/recursion.rs`
- Detect self-recursive functions with pattern `F(n) = if n <= base { ... } else { return F(n - 1) + F(n - 2); }`.
- Transform the function into an unrolled recursive form:
  - Base cases for `n <= 1`, `n == 2`, `n == 3` with direct scalar returns.
  - Recurrence expansion `3 * F(n - 3) + 2 * F(n - 4)` (or depth 1: `2 * F(n - 2) + F(n - 3)`).
- Preserve exact type definitions, spans, and bit-for-bit mathematical results.

#### [MODIFY] `src/lib.rs`
- Export `pub mod opt;`.

#### [MODIFY] `src/codegen/cranelift_backend.rs`
- Invoke `numlang::opt::optimize_program` at the beginning of `compile_program` / `compile_to_obj`.

### Tests
#### [NEW] `tests/recursion_opt_test.rs`
- Verify mathematical correctness for `fib(0)` through `fib(35)`.
- Confirm identical values between unrolled and un-unrolled implementations.
