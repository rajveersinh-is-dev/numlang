<objective>
Implement static induction variable analysis and bounds check safety tracking in the typechecker.

Purpose: Detect at compile time when an array index is guaranteed to be within bounds, so the backend can omit runtime bounds checks.
Output: `is_safe` annotations in `src/typecheck/typed_ast.rs` and analysis in `src/typecheck/checker.rs`.
</objective>

<execution_steps>
1. Extend `TypedExpr::Index` and `TypedStmt::IndexAssign` in `src/typecheck/typed_ast.rs` with `is_safe: bool`.
2. In `src/typecheck/checker.rs`, implement range tracking:
   - For constant indices `arr[c]`: if `c >= 0 && c < arr.len`, set `is_safe = true`.
   - For loop induction variables: when typechecking `while i < limit`, track `(i, limit)` in the active loop environment and mark accesses `arr[i]` where `arr.len >= limit` as `is_safe = true`.
3. Update existing match sites in `src/codegen/cranelift_backend.rs` and `src/ir/lower.rs` to handle `is_safe`.
4. Write unit tests in `tests/bce_tests.rs` asserting that `is_safe` is properly set.
</execution_steps>
