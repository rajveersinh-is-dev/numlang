<objective>
Implement the primary CLI driver subcommands (`build`, `run`, `check`) while maintaining backward compatibility with compiler diagnostic flags.

Purpose: Provide standard, ergonomic compiler commands where developers can compile and run their programs directly with `numlang run <file.nl>` or build standalone binaries with `numlang build <file.nl> -o <binary>`.
Output: Refactored `src/main.rs` with Clap subcommands and integration tests in `tests/cli_driver_tests.rs`.
</objective>

<execution_steps>
1. Refactor CLI argument parsing in `src/main.rs` to support `Commands::Build`, `Commands::Run`, `Commands::Check`, as well as top-level flags.
2. Implement `build` command logic: compile source -> emit object -> link executable (with default output file path if `-o` is not provided).
3. Implement `run` command logic: compile source -> emit temp object -> link temp executable -> run executable -> delete temp files -> exit with child status.
4. Write integration tests in `tests/cli_driver_tests.rs` verifying `numlang build` and `numlang run`.
</execution_steps>
