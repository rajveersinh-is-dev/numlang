# Plan 34-01: Bounded While-Loop Unrolling & Exponentiation Expansion

**Phase:** 34 - Bounded While-Loop Unrolling & Exponentiation Expansion  
**Requirements:** UNROLL-01, UNROLL-02  
**Status:** Planned  

## Objective

Implement bounded while-loop unrolling and constant exponentiation expansion in the compiler to eliminate 20M+ loop branches, condition tests, and divisions in `pow_mod`, driving Modular Exponentiation runtime from 44.36 ms to < 18 ms (crushing Rust at 24.57 ms).

## Implementation Details

1. **Constant Value Tracking for Loop Variables (`src/codegen/cranelift_backend.rs` or `src/opt/`):**
   - Track local variables that have known constant values at while-loop entry points.
   - For `pow_mod` inlined into `mod_pow_accumulator`:
     `let mut e: i64 = 13;`
     `while e > 0 { ... e = e / 2; }`
     The loop condition variable `e` begins with a compile-time constant integer value (e.g. 13).

2. **Full Loop Unrolling for Bounded While-Loops (`UNROLL-01`):**
   - When a while loop condition depends on a variable with a known initial constant, and each iteration updates that variable deterministically (e.g. `e = e / 2`, `e = e >> 1`, or `i = i + 1`):
   - If the total trip count is known at compile time and `<= 16`:
     - Simulate/expand the iterations directly into straight-line statements!
     - In each iteration, dead branches (such as `if e % 2 == 1` where `e` is an odd/even constant at that step) are evaluated at compile-time, pruning the un-taken branch completely!
     - The variable assignments (`e = e / 2`) become constant definitions, eliminating all runtime division instructions for `e`.

3. **Constant Exponentiation Straight-Line Expansion (`UNROLL-02`):**
   - When `pow_mod(base, exp, m)` or the loop `while e > 0` has constant exponent `E`:
     - Bit 0: `E & 1 == 1` -> `res = (res * b) % m`, `b = (b * b) % m`
     - Bit 1: `(E >> 1) & 1 == 0` -> only `b = (b * b) % m`
     - Bit 2: `(E >> 2) & 1 == 1` -> `res = (res * b) % m`, `b = (b * b) % m`
     - Bit 3: `(E >> 3) & 1 == 1` -> `res = (res * b) % m`
     - Zero loop overhead, zero branch mispredictions, pure pipelined arithmetic.

4. **Integration & Verification:**
   - Add unit tests verifying bounded while-loop unrolling and exponentiation expansion.
   - Benchmark Modular Exponentiation (5M iters) with high-resolution in-process QPC telemetry.
   - Verify bit-for-bit identical exit code (211).
