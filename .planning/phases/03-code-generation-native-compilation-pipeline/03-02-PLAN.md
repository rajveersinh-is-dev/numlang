<objective>
Implement the Cranelift code generation backend, COFF object file emission, Windows linker driver, and produce standalone Windows x86_64 executable binaries.

Purpose: Deliver end-to-end native machine code generation and linking so numlang programs run on bare metal Windows x86_64.
Output: Cranelift backend in `src/codegen/`, Windows linker driver, CLI support for `--emit-obj` and `--output` / `-o <file.exe>`, and executable execution tests.
</objective>

<execution_steps>
1. Add Cranelift dependencies (`cranelift-codegen`, `cranelift-frontend`, `cranelift-module`, `cranelift-object`, `cranelift-native`, `target-lexicon`) to `Cargo.toml`.
2. Create `src/codegen/cranelift_backend.rs` translating typed AST/IR into Cranelift SSA functions.
3. Emit COFF object files (`.obj`) via `cranelift-object`.
4. Create `src/codegen/linker.rs` implementing toolchain discovery (`rust-lld.exe` in Rust sysroot or MSVC `link.exe`), library search path resolution, and linking commands.
5. Update `src/main.rs` with `-o / --output` and `--emit-obj` options.
6. Write integration tests in `tests/codegen_tests.rs` verifying that compiled `.exe` files run and produce expected results.
</execution_steps>
