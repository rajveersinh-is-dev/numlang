<objective>
Build an automated, reproducible comparative benchmarking harness evaluating numlang native binaries against optimized C and Rust reference implementations across compute-heavy mathematical workloads.

Purpose: Validate that numlang fulfills the project vision of bare-metal execution speed without garbage collection overhead.
Output: A comparative benchmark harness in `tests/benchmark_harness.rs` executing benchmarks (Fibonacci/recursion, iterative math accumulator, vector dot product) with millisecond-precision timing and comparative speedup reporting.
</objective>

<execution_steps>
1. Identify and verify available C (MSVC `cl.exe` or `clang.exe`) and Rust (`rustc.exe`) compiler toolchains on the host system.
2. Implement computational microbenchmarks in:
   - numlang: recursive fibonacci, math loops with sqrt/abs, vector dot product.
   - C: identical algorithms compiled with `/O2` (or `-O3`).
   - Rust: identical algorithms compiled with `rustc -O`.
3. Build the automated benchmark harness in `tests/benchmark_harness.rs`:
   - Compiles each benchmark into standalone native executables.
   - Runs each binary over multiple timed iterations (warmup + measured runs).
   - Verifies numerical output correctness (exit codes or printed values).
   - Collects elapsed runtimes, computes min/avg times, and generates a structured comparison report.
4. Tune Cranelift backend flags if needed for maximum throughput (opt_level "speed", inlining).
5. Run the full benchmark suite and record verified performance results.
</execution_steps>
