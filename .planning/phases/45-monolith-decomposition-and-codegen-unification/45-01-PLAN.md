# Phase 45: Monolith Decomposition & Codegen Unification — Plan

> **Phase**: 45  
> **Status**: Completed  
> **Traceability**: `ADVERSARIAL_AUDIT.md` §4.1, §4.2, §5  

## Objective
Deconstruct the 9,300+ line Cranelift monolith into modular submodules under `src/codegen/cranelift/` (each strictly $\le 2,500$ lines). Unify backend compilers under a `BackendCompiler` trait. Eliminate all bare `.unwrap()` / `.expect()` in backend codegen. Purge deprecated legacy AST supercompiler passes in `src/opt/supercompiler/`. Implement inductive SMT loop validation ($k$-induction) in `src/mir/supercompiler/validate.rs`.

## Requirements
- **CODEGEN-01**: Partition Cranelift backend into `src/codegen/cranelift/` (`mod.rs`, `abi.rs`, `intrinsics.rs`, `escape.rs`, `ast_stmt.rs`, `ast_expr.rs`, `mir_emit.rs`). Retain `src/codegen/cranelift_backend.rs` as a thin forwarding shim.
- **CODEGEN-02**: Enforce strict file size bound: no file exceeds 2,500 lines.
- **CODEGEN-03**: Define `BackendCompiler` trait in `src/codegen/backend_trait.rs` and implement for `CraneliftCompiler` and `LlvmCompiler`.
- **CODEGEN-04**: Replace all bare `.unwrap()` / `.expect()` in codegen with structured `CodegenError` variants.
- **CODEGEN-05**: Purge deprecated `src/opt/supercompiler/` directory.
- **CODEGEN-06**: Implement $k$-induction loop translation validation in `src/mir/supercompiler/validate.rs`.
