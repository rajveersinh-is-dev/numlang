# Plan 29-01: Whole-Program Interprocedural Function Inlining

**Phase:** 29 — Whole-Program Interprocedural Function Inlining  
**Requirements:** INLINE-01, INLINE-02  
**Status:** In Progress  

## Objective

Implement an interprocedural function inlining pass (`src/opt/inlining.rs`) in the NumLang optimizer that:
1. Detects calls to non-recursive, eligible functions (such as `pow_mod`, `is_prime`, `isqrt_newton`, `stein_gcd`, `collatz_steps`).
2. Clones the callee body into the caller AST, binding parameter arguments to unique scoped local variables and mapping return values to the call target.
3. Exposes inlined constants (e.g. `exp = 13`, `m = 1000000007`) to downstream constant propagation and strength-reduction passes.
4. Slashes millions of function call instructions and stack frame allocations in critical inner loops.

## Implementation Details

1. **Inlining Eligibility**:
   - Callee is non-recursive (no direct or indirect self-calls).
   - Callee does not contain unsupported complex return patterns (single exit or clean single-block returns, or early return converted to conditional assignment).
   - Callee has moderate AST size (e.g. <= 60 statements).
2. **Variable Renaming & Hygenic Splicing**:
   - Generate unique prefixes (`__inl_{callee}_{call_id}_{var}`) for all parameters and local variables in the inlined body to prevent variable capture or shadowing.
   - Bind parameter arguments: emit `let mut __inl_param = arg;` for each parameter.
   - For single-return callees: replace `return expr` with assignment to `let mut __inl_ret = expr;`.
   - Splice the inlined statements directly into the enclosing block before the statement containing the call.
3. **Integration**:
   - Wire `inlining::optimize_program(program)` into `src/opt/mod.rs` as the first pass before `const_args` and `math_elevation`.
   - Re-run `const_args` after inlining so inlined parameters that receive constants are propagated into constant modulo/div strength reduction.

## Verification Plan

### Automated Tests
- Add `tests/inlining_tests.rs` testing inlining of single-return functions, functions with loops, constant arguments, and ensuring mathematical equivalence.
- Verify `pow_mod` dynamic benchmark runtime drops significantly.
- Run workspace tests (`cargo test`) to ensure zero regressions.
