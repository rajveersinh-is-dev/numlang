# Phase 41: Decouple Win32 and True POSIX Native Codegen — Plan

> **Phase**: 41  
> **Status**: Completed  
> **Traceability**: `ADVERSARIAL_AUDIT.md` §3.2, §3.3  

## Objective
Eliminate hardcoded Windows `kernel32.lib` imports (`ExitProcess`, `GetStdHandle`, `WriteFile`, `LocalAlloc`) when compiling on or targeting non-Windows operating systems (Linux, macOS, Docker). Provide standard POSIX libc system calls (`exit`, `write`, `malloc`). Ensure arithmetic safety in order-2 recurrence solving in `generalize.rs`.

## Requirements
- **PORT-01**: In `src/codegen/cranelift_backend.rs`, conditionally declare Win32 APIs only when targeting Windows. On non-Windows platforms, declare standard C library `exit` and `write`.
- **PORT-02**: In `src/codegen/llvm_backend.rs`, dynamically target the host triple and emit conditional `exit` and `write` signatures for non-Windows targets.
- **PORT-03**: Update `src/codegen/entry_bench.c` with `#ifdef _WIN32` portability branch using `clock_gettime(CLOCK_MONOTONIC)` on POSIX.
- **PORT-04**: Implement checked integer arithmetic (`checked_mul`, `checked_add`) and non-zero divisor guard in `src/mir/supercompiler/generalize.rs` for order-2 linear recurrences.
- **PORT-05**: Create `tests/platform_portability_tests.rs` verifying absence of undefined Windows symbols on non-Windows builds.

## Verification

- `cargo test --tests` passes all suites with 0 regressions.
